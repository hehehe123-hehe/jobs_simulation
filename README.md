# Data Analytics — Forage Job Simulations

A collection of completed [Forage](https://www.theforage.com) virtual job simulations in the Data & Analytics track. Each folder corresponds to the sponsoring company and contains the completed tasks/files for that simulation.

> **Note:** These are self-paced virtual job simulations, not employment or internship experience. Per Forage's own guidance, they're listed here as completed certifications/practice projects, not as work history.

## Simulations Completed

### 📁 BCG
- **[Data Science](https://www.theforage.com/simulations/bcg/data-science-ccdz)** — Built a churn prediction model (Random Forest) for a simulated energy client.
- **[Introduction to Data for Decision Makers](https://www.theforage.com/simulations/bcg/data-for-decision-makers-tod0)** — Analyzed campaign data and communicated findings as business recommendations.

### 📁 CITY (Citi)
- **[Markets Quantitative Analysis (MQA)](https://www.theforage.com/simulations/citi/global-quantitative-analysis-analyst-6b4m)** — Applied financial math, commodity pricing, hedging, and risk management to market scenarios.

### 📁 Deloitte
- **[Data Analytics (Deloitte Australia)](https://www.theforage.com/simulations/deloitte-au/data-analytics-s5zy)** — Built a Tableau dashboard for factory telemetry data and used Excel to classify compensation fairness.

### 📁 commonwealth_bank
- **[Introduction to Data Science](https://www.theforage.com/simulations/commonwealth-bank/intro-data-science-sd7t)** — Built a data engineering pipeline to aggregate, analyze, and anonymize a large dataset.

### 📁 forage (Forage Academy)
- **[Data Labeling](https://www.theforage.com/simulations/forage/data-labeling-c1t0)** — Labeled data for intent, sentiment, and PII, then reviewed labels for quality.
- **[Excel Skills](https://www.theforage.com/simulations/forage/sponsored-content-excel-skills-jf8r)** — Practiced core Excel: data prep, formulas, charts, and automation.
- **[Excel Skills for Business Finance](https://www.theforage.com/simulations/forage/sponsored-content-excel-skills-for-busi-xue7)** — Built a 5-year financial forecast model (P&L, cash flow, debt).

## Skills Demonstrated
- Data analysis and predictive modeling (Python, Random Forest)
- Data visualization and dashboarding (Tableau)
- Advanced Excel — formulas, financial forecasting, data classification
- Data pipeline design, aggregation, and anonymization
- Quantitative and financial analysis
- Data labeling, quality review, and privacy-aware data handling
