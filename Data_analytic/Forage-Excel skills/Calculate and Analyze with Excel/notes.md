#Put Formulas Into Practice
Now it’s time to apply the formulas and functions you’ve learned. Download the Excel Formula Practice workbook below and open it in Microsoft Excel. The workbook includes account sales data and several blank calculation columns for you to complete.

Your task
Create formulas to calculate the following for each account:

Total Unit Sales using =SUM.
Average Annual Unit Sales using =AVERAGE.
Highest Annual Unit Sales using =MAX.
Lowest Annual Unit Sales using =MIN.
Sales Level using =IF and the threshold provided in the workbook.
Sales Change using =IFERROR so a calculation error does not appear in the worksheet.
Copy each formula down the column so it calculates a result for every account.

Complete the summary calculations
In the summary section of the workbook:

Use =COUNTIF to count the number of accounts with Product 2.
Use =SUMIF to calculate total 2021 unit sales for Retail accounts.
When creating your Sales Level formula, make sure the threshold cell uses an absolute reference so it stays fixed when you copy the formula down.

Submit your work
Save and submit your completed Excel workbook. Before submitting, review your formulas and make sure each calculation returns the expected result.
