#Prepare Your Data for Visualization
Before creating a chart, make sure your data is organized in a way Excel can work with easily. For this task, you’ll use a clean copy of the Account Sales Data workbook, which is available for download below

Download the workbook
Open the workbook in Excel and take a moment to review the columns and how the data is structured.

Convert the data into an Excel Table
Excel Tables make it easier to manage, sort, filter, and reference data when building charts and PivotTables.

To create a table:

Select any cell in the dataset.
Press Ctrl + T.
Confirm that the correct data range is selected.
Make sure My table has headers is checked.
Select OK.
Use PivotTables to summarize data
A PivotTable lets you reorganize and summarize a dataset without changing the original data.

You can use PivotTables to:

Combine values into totals.
Compare categories.
Group information by year or account type.
Create a cleaner source for charts.
To insert one:

Select a cell inside your Excel Table.
Select Insert > PivotTable.
Choose where you want the PivotTable to appear.
Add fields to the Rows, Columns, and Values areas based on what you want to summarize.
Keep your original dataset intact and use separate worksheets for any PivotTables or dashboard content you create.
