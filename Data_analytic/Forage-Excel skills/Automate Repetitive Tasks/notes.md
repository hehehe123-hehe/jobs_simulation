# Record and Run a Macro
You’ll use a clean copy of the Account Sales Data workbook for this task. Download the workbook below, then open it in the desktop version of Microsoft Excel.

Before recording your first macro, save the workbook as an Excel Macro-Enabled Workbook (.xlsm). This file type is required to preserve the macros you create.

Save your workbook as a macro-enabled file
Select File > Save As.
Choose where you want to save the workbook.
Under file type, select Excel Macro-Enabled Workbook (.xlsm).
Save the workbook.
You’ll use this same workbook to create and test both macros.

Step 1: Turn on the Developer tab
If you do not see Developer in the Excel ribbon:

Windows

Select File > Options > Customize Ribbon.
Check Developer under Main Tabs.
Select OK.
Mac

Select Excel > Settings/Preferences > Ribbon & Toolbar.
Under Main Tabs, check Developer.
Save or close the settings window.
Step 2: Record a macro
Select Developer > Record Macro.
Give your macro a clear name without spaces.
Under Store macro in, select This Workbook.
Select OK.
Complete the Excel actions you want to automate.
Select Developer > Stop Recording when finished.
Excel saves those actions as a macro.

Step 3: Test your macro
Select Developer > Macros, choose your macro, and select Run. Check the workbook to make sure Excel repeated the actions correctly.

Step 4: View the VBA code
To see the code Excel created, select Developer > Macros, choose your macro, and select Edit. You do not need to write VBA code yourself. For now, focus on understanding how recorded Excel actions become an automated workflow.
